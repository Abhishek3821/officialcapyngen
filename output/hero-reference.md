# Destination hero

Rebuilt in React, TypeScript, Tailwind, CSS, and the Web Animations API from the user's video reference. No animation library or third-party slider code is included.

The recording depicts the [Timed Cards Opening reference](https://codepen.io/dilums/pen/NWodZMd). Its public asset collection currently serves different photographs from those in the recording. This implementation uses scene-matched photography, not an exact photographic reproduction.

The following reference asset collection supplied the desert, Yosemite, coast, and Cappadocia scenes:

- https://assets.codepen.io/3685267/timed-cards-3.jpg
- https://assets.codepen.io/3685267/timed-cards-4.jpg
- https://assets.codepen.io/3685267/timed-cards-5.jpg
- https://assets.codepen.io/3685267/timed-cards-6.jpg

The alpine-cyclist and snow-monkey scenes are sourced from:
